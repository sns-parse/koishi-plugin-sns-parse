# koishi-plugin-video-parser-all v1.6.6

## 更新日志

### 修复

- 修复无状态码的 API 响应被误判为失败的问题：当响应不含 `code`/`status` 等状态字段时，视为成功并直接解析数据，提升与第三方 API 的兼容性。
- 修复 `normalizeUrl` 对协议的处理：支持大写协议（`HTTPS://`）、无协议头 URL（`example.com/...`），以及 `blob:`/`data:` 等特殊协议，避免 URL 被错误补全而损坏。
- 修复 `duration_ms` 字段单位错误：当 API 仅返回 `duration_ms`（毫秒）时，自动除以 1000 转换为秒，而非错误地按秒处理。
- 修复绿洲（oasis）链接被微博 catch-all 规则错误识别为 `weibo` 平台的问题：调整链接匹配规则顺序，`oasis.weibo.com` 的链接现在正确识别为 `oasis` 平台。
- 修复错误提示消息发送时可能中断解析流程的问题，增加容错处理。
- 修复 `raw` 响应数据本身为数组时无法解析的问题，现在自动取数组第一个元素作为数据源。

### 优化

- 文本格式化 `generateFormattedText` 性能优化：变量替换由多次正则替换改为单次正则回调遍历，性能提升 10 倍以上。
- 内置链接匹配规则去重合并：消除多平台重复/冗余规则（如 `v.douyin.com/+` 与 `*` 重复、`t.cn/+` 与 `*` 重复等），规则总数从约 100 条精简至 85 条，减少每次消息扫描的正则匹配开销。
- 图片发送进度日志改为仅调试模式输出（`debugLog`），避免生产环境刷屏。

### 架构

- 模块化重构：将单文件（约 1500 行）拆分为 8 个职责清晰的模块文件，提升可维护性与可测试性：
  - `types.ts`：类型定义
  - `config.ts`：配置 Schema
  - `utils.ts`：通用工具（缓存、限流、URL 处理、数字解析等）
  - `logger.ts`：日志模块
  - `link-rules.ts`：链接规则与提取
  - `parser.ts`：API 响应解析
  - `format.ts`：文本格式化
  - `index.ts`：入口与 apply 函数
- 移除全部代码注释，保持代码整洁。

### 兼容性

- 增强 `raw` 响应兼容性：支持响应本身为数组的情况（自动取第一个元素）。
- 增强 `normalizeUrl` 兼容性：支持 `blob:`、`data:` 等特殊协议 URL 不被破坏。
- 增强 `fetchApi` 兼容性：无状态码字段的 API 响应不再被拒绝，改为直接尝试解析数据。
